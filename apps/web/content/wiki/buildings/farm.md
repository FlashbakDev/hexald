## Description

La **ferme** produit du blé sur les plaines. Le blé nourrit la chaîne alimentaire (moulin → farine → boulangerie) et sert aussi en secours selon les règles du village.

## Construction

- Terrain : **plaine**
- Pas de tech requise

Poser une ferme sur un troupeau ou un gisement d’argile **efface** le POI. Préfère une plaine vide quand c’est possible.

## Production

Ouvrier fermier → blé / min. Stocké jusqu’au plafond blé.

## Conseils

Une ferme active + maisons = croissance pop plus sereine. Le moulin n’a d’intérêt qu’avec un surplus de blé.
